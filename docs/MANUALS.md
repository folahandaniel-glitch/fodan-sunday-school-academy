# Manuals

## Super Admin
Sign in at `/login` (change the temporary password, turn on two-step verification in My Profile). **Content review**: read each curriculum, Approve (freezes it), Publish. **Completeness Report** shows every unit's status. **Curriculum Library**: create/edit lessons, question banks and blueprints; start a new draft version to improve a frozen one; import DOCX/PDF/text (always as a draft) and CSV questions; export DOCX. **Churches**: approve, suspend (reason required), merge unverified listings, grant plans. **Plans**: set real prices/limits. **Website / Branding**: edit pages, navigation, colours, logos and where each logo is used. **Settings**: registration rules, grade scale, certificate wording.

## Church administrator
Register the church; approve members (or share the join code); create classes, assign teachers, enrol learners; **Library → Start a programme** (pick session dates, holidays, assessment weeks; confirm the proposed 26 dates); activate. Reschedule without losing lessons; adopt newer curriculum versions when you choose. Manage assessments, release results, issue certificates, download reports.

## Teacher
Open a lesson for notes and facilitator guidance, mark delivered, take attendance, run discussions, set assignments, mark written exam answers (Grading queue), release results where permitted.

## Learner
Lessons open on their date; read, discuss, complete assignments, take tests (answers autosave; the timer is the server's), view released results and certificates. Everyone can use the community forum.
